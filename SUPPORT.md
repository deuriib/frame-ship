# Getting Support for frame-ship

Thank you for building with `frame-ship`. We are committed to fostering a supportive community. This guide outlines how to find answers, where to ask questions, and how to report issues effectively.

## Where to Get Help

To keep our community organized and help other developers find answers quickly, please use the appropriate channel below:

| Need | Channel | Link |
| :--- | :--- | :--- |
| **Questions & Usage Help** | GitHub Discussions (Q&A) | [GitHub Discussions](https://github.com/deuriib/frame-ship/discussions) |
| **Feature Requests & Ideas** | GitHub Discussions (Ideas) or Issue Form | [New Feature Request](https://github.com/deuriib/frame-ship/issues/new?template=2-feature-request.yml) |
| **Bug Reports & Defects** | GitHub Issues (Bug Report) | [New Bug Report](https://github.com/deuriib/frame-ship/issues/new?template=1-bug-report.yml) |
| **Security Vulnerabilities** | Private Security Advisory | See [SECURITY.md](SECURITY.md) / `deuriib@gmail.com` |
| **Code of Conduct Violations** | Conduct Enforcement | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) / `deuriib@gmail.com` |

---

## 1. Questions, Discussions, and Best Practices

If you have questions about how `frame-ship` works, how to configure skills for specific coding agents (OpenCode, Antigravity CLI, Claude Code), or how to adapt the delivery methodology to your team:

- **Channel**: [GitHub Discussions](https://github.com/deuriib/frame-ship/discussions)
- **What to do**:
  1. Search existing discussions and answered questions to see if your topic has already been addressed.
  2. If not, open a new discussion under **Q&A** or **General**.
  3. Include your harness environment (e.g. OpenCode version, Node.js version, OS).

---

## 2. Reporting Bugs and Issues

If you encountered a broken workflow, an unexpected error, a type error, or a regression in `frame-ship`:

- **Channel**: [GitHub Issues](https://github.com/deuriib/frame-ship/issues)
- **What to do**:
  1. Search [existing open and closed issues](https://github.com/deuriib/frame-ship/issues) to avoid duplicate reports.
  2. If reproducible, submit a new issue using our structured template:
     - Clear description of the unexpected behavior vs. expected behavior.
     - Minimal reproduction steps.
     - Environment details (Node.js version, OS, harness version).
     - Relevant error logs or terminal output.

## Urgent Escalations

If a critical regression in `frame-ship` completely blocks downstream developer agent workflows and cannot wait for standard issue triaging:

- **Direct Email**: `deuriib@gmail.com`
- **Subject**: `[URGENT BUG] frame-ship: <short description>`
- Please include a link to the corresponding GitHub Issue so resolution remains transparent to the broader community.
