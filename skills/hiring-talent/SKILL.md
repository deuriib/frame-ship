# Hiring Talent

## Overview

**Hiring IS scorecard-first selection applied to people decisions.**

You define the scorecard (outcomes + competencies + evidence), watch unstructured hiring fail against it (baseline bias), run structured selection, and only then decide. No offer without evidence.

**Core principle:** If you didn't write the scorecard before seeing candidates, you don't know if you're selecting for the work or for likability.

**REQUIRED BACKGROUND:** You MUST understand people:discovering-needs before using this skill. That skill defines the brief. This skill executes selection against it.

## The Iron Law

```
NO OFFER WITHOUT SCORECARD EVIDENCE
```

If the scorecard doesn't exist and every criterion doesn't have interview evidence behind it, you cannot recommend a hire.

## Scorecard First (RED-GREEN for hiring)

| Hiring step | Maps to |
|---|---|
| **Scorecard** | The test: outcomes, competencies, knockout criteria |
| **Unstructured screen (RED)** | Gut-feel review that the scorecard would reject |
| **Structured process (GREEN)** | Every criterion gets dedicated evidence |
| **Decision** | Only when evidence covers the scorecard |

## Checklist

Create a todo per item. Complete in order.

1. **Scorecard** — mission for the role, 3-5 outcomes (first 12 months), 4-6 competencies with observable behaviors, knockout criteria, compensation band. Get human approval BEFORE sourcing.
2. **Sourcing plan** — channels, outreach volume target, timeline, who screens. Confirm budget and band sign-off.
3. **Screen** — knockout check + one scorecard criterion minimum per screen. Log evidence per criterion, never "good vibes".
4. **Structured interviews** — each interview owns 1-2 competencies, same questions per candidate, scoring rubric 1-4 with behavioral anchors. No repeat-the-resume rounds.
5. **Debrief** — score independently BEFORE discussing. Compare criterion by criterion. Reference checks target unverified criteria only.
6. **Decision + offer** — hire only when every knockout passes and no competency scores below bar. Offer letter states outcomes for first 90 days.
7. **Onboarding 30-60-90** — written plan with owner per milestone, week-1 access checklist, 30/60/90 check-ins scheduled before day one.

## Interview Rules

- Same questions per candidate for the same competency. Different questions = different bars = bias.
- Score independently first, then deliberate. Discussion before scoring anchors the loudest voice.
- "Culture fit" is banned as a criterion. Use "culture add + values behaviors" with observable examples.
- Every rejection gets a scorecard reason. "Not a fit" without criterion evidence is a process failure — rewrite it.
- Keep a hiring log: candidate → criterion → score → evidence quote. Review it before the debrief.

## Red Flags — STOP

| Thought | Reality |
|---------|---------|
| "Great resume, let's fast-track" | Resumes predict nothing. Scorecard evidence decides. |
| "Amazing culture fit" | Fit without behaviors is affinity bias. Name the behavior. |
| "We need someone ASAP, skip the scorecard" | Urgency is how mis-hires happen. Scorecard first, then speed. |
| "The hiring manager already loves them" | Pre-commitment corrupts scoring. Score blind to the preference. |
| "One interview is enough for this level" | One interview measures confidence, not competence. Structure scales with impact, not title. |
| "Let's keep them warm while we decide" | Delay without a decision date loses candidates. Decide on the debrief date or say so. |
| "Offer first, figure out onboarding later" | Unhired onboarding is turnover in 90 days. 30-60-90 before day one. |

## Rationalization Prevention

| Excuse | Reality |
|--------|---------|
| "Should be a great hire" | Show the scorecard coverage. |
| "I'm confident in my read" | Confidence ≠ evidence. Scores first. |
| "Just this once, skip reference checks" | No exceptions on senior or trust roles. |
| "The team liked them" | Likability isn't on the scorecard unless the work needs it. |
| "Different role so the scorecard doesn't apply" | Then write the right scorecard before deciding. |

## Verification

Before recommending hire / no-hire:

1. **IDENTIFY:** Scorecard coverage — every criterion has ≥1 evidence entry?
2. **RUN:** Read the hiring log end to end, check scores and quotes.
3. **READ:** Knockouts all pass? Any competency below bar?
4. **VERIFY:** Gaps → no-hire or targeted final round. Full coverage → hire with 90-day outcomes.
5. **ONLY THEN:** State the recommendation WITH the evidence table.

## When To Apply

- Opening or backfilling any role
- Writing or changing a job description or scorecard
- Screening, interviewing, debriefing, referencing, offering
- Designing onboarding for a new hire
- Using agencies, RPO, or internal mobility for the role
