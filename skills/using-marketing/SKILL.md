## The Rule

**Invoke the relevant marketing skill BEFORE any response or action** — including clarifying questions, exploring analytics, or checking files. If it turns out wrong for the situation, you don't have to use it.

Then announce "Using [skill] to [purpose]" and follow the skill exactly. If it has a checklist, verify each item.

## Los 4 principios

1. **ROI es Dios.** Toda acción declara su retorno esperado o se descarta. Sin métricas vanidosas.
2. **Search intent manda.** CTR + permanencia sobre keyword stuffing. Google premia al que satisface, no al que repite.
3. **Velocidad > perfección.** Lanzar, medir datos reales, optimizar. Parálisis por análisis es pérdida.
4. **Rangos C/B/A/S.** Clasifica cada web antes de invertir: C = experimento barato, B = tracción, A = rentable, S = escalar agresivo.

## Skill Priority

Nicho → keywords → contenidos → copy → enlaces → monetizar → escalar:

- "¿En qué nicho entro?" → `nichos-rangos` primero.

- "Necesito enlaces" → `enlaces-flota` primero.

- "¿Qué escalo / qué falla?" → `escalar-analitica` primero.

## Red Flags

| Thought | Reality |
|---------|---------|
| "Esto es solo branding" | Branding sin retorno es gasto. Declara el ROI o dropea la tarea. |
| "Publiquemos y ya" | Publicar sin intent clasificado es canibalización futura. Clasifica primero. |
| "Más tráfico = mejor" | Tráfico sin conversión es vanidad. Qué intent, qué monetización. |
| "El diseño primero" | Web pesada mata conversión. Ligera y que venda, luego bonita. |
| "Compramos enlaces y listo" | Enlaces sin flota ni intent son humo. Mapa de flota primero. |

## Guardrails

Lee `references/guardrails.md` antes de actuar. Si un gate falla, la tarea se pausa y se escala. Sin excepciones.

## Checklist

- [ ] ROI esperado declarado (qué retorno, en qué plazo).
- [ ] Search intent clasificado (transaccional / informacional / inbound).
- [ ] Rango asignado (C / B / A / S) antes de invertir esfuerzo.
- [ ] Métrica de éxito definida (CTR, conversión, RPM, posición — una, no cinco).
- [ ] Guardrails verificados (`references/guardrails.md`) o bloqueo escalado.
