# Diagnosing People Problems

## Overview

**Diagnosis IS root-cause analysis applied to people pain.**

You reproduce the pattern with data, form theories, test the cheapest one first, and only then prescribe. Fixing before diagnosing treats symptoms and keeps the disease.

**Core principle:** If you haven't named the pattern with data (who, where, when, how often), you don't have a problem — you have an anecdote.

## The Iron Law

```
NO PEOPLE FIX WITHOUT A NAMED, EVIDENCED ROOT CAUSE
```

If the diagnosis doc doesn't name the cause with data behind it, no reorg, no PIP wave, no policy change, no announcement.

## Checklist

Create a todo per item. Complete in order.

1. **Name the symptom precisely** — who is affected, where, since when, how often, how severe. One paragraph with numbers. "Morale is low" is not a symptom; "regretted attrition in Support Tier-2 tripled since March" is.
2. **Gather data** — engagement cuts, exit themes, attendance, performance distribution, 1:1 themes, comp position. Minimum two independent sources before theorizing.
3. **Form 2-3 theories** — manager quality, compensation, workload, clarity, growth, selection-miss, external market. Rank by fit to the data.
4. **Test cheapest first** — 5 stay interviews, skip-level sample, band check, workload audit. One probe per theory, smallest cost first.
5. **Name the root cause** — one sentence: cause → mechanism → symptom. Write it down, get human-partner agreement.
6. **Prescribe once** — match the fix to the cause via the right talent skill (hiring, reviewing, shaping, growing). Cause without prescription is trivia; prescription without cause is malpractice.
7. **Follow-up date** — metric + date to confirm the fix worked. No follow-up = no learning.

## Common Patterns

| Symptom | Usual suspects (test in order) |
|---|---|
| Regretted attrition spike | Manager quality → comp position → workload → growth path |
| Team conflict | Unclear ownership → competing incentives → selection-miss → style clash (last) |
| Absenteeism rise | Burnout load → disengagement → manager avoidance → health/external |
| Engagement drop | Change fatigue → clarity loss → recognition gap → comp surprise |
| Performance cluster-low | Unclear goals → missing skills (hire/train) → low bar tolerance → tool/process friction |
| Complaint / grievance | Process first (listen, document, protect), then pattern-check: isolated vs. systemic |

## Investigation Rules

- Listen first, document contemporaneously. Memory edits; notes don't.
- Protect reporters: confidentiality explicit, retaliation banned and monitored. A broken reporting channel hides the next ten problems.
- Separate the person from the pattern: fix the person with reviewing-performance, fix the pattern with shaping-culture. Never reorg around one person.
- External market is a hypothesis, not an excuse. Check bands and offers before blaming "the market".
- Complaints and legal-risk signals (harassment, discrimination, safety) escalate to qualified counsel/HR legal immediately — this skill structures the intake, never replaces legal advice.

## Red Flags — STOP

| Thought | Reality |
|---------|---------|
| "I know what the problem is" | You have a theory. Data first, then the cause. |
| "Let's just PIP the bottom 10%" | PIP waves without diagnosis punish symptoms and terrify survivors. Diagnose first. |
| "It's a culture problem, reorg now" | "Culture problem" is not a diagnosis. Name the mechanism. |
| "One complaint, let's overhaul policy" | One data point is an intake, not a pattern. Investigate proportionally. |
| "Engagement will recover on its own" | Untreated causes compound. Name it, fix it, follow up. |
| "The manager says the team is fine" | The manager is one source. Triangulate before concluding. |
| "Legal will handle it, we do nothing" | Legal handles liability. You still fix the pattern. Both tracks run. |

## Verification

Before prescribing ANY fix:

1. **IDENTIFY:** Symptom paragraph + data sources + root-cause sentence — all written?
2. **RUN:** Re-read the data. Does the cause explain ALL the data, including the inconvenient parts?
3. **READ:** Cheapest theory tested? Alternative causes ruled out with evidence, not preference?
4. **VERIFY:** Cause holds → prescribe via the matching talent skill. Cause shaky → test the next theory.
5. **ONLY THEN:** Act — and set the follow-up metric + date before closing.

## When To Apply

- Attrition, regretted exits, turnover clusters
- Conflicts, complaints, grievances, investigations intake
- Absenteeism, burnout signals, engagement drops
- Performance patterns across a team
- "Something feels off" — turn the feeling into a symptom paragraph first
