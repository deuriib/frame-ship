# Pricing & Packaging

## Overview

Price is the bet made legible. Never set prices from costs or competitors alone — from willingness-to-pay evidence tied to the job.

**Announce at start:** "I'm using the pricing-packaging skill to shape this pricing decision."

## The Flow

### 1. Anchor on the job

- Which JTBD does each tier serve? One tier = one job intensity, not a feature pile.
- Name the value metric (the unit that scales with user success: seats with outcome, sends, projects, revenue touched). If the metric doesn't scale with value received, it's the wrong metric.

### 2. Evidence before numbers

Cheapest probe that can kill the price, in order: Van Westendorp slice (4 questions, 20 users) → fake-door price test → concierge at price → priced pilot with one payer. No evidence, no price.

### 3. Structure the offer

- **Good / Better / Best**, 3 tiers max. Middle tier is the target — make it the obvious choice (anchor high, decoy low).
- Each tier: who it's for (segment + job), value metric + included quota, ONE differentiator above it, price with charm removed (round numbers signal confidence for B2B; .99 signals deal for self-serve — pick deliberately).
- **Explicit non-goals:** what each tier does NOT include, and where that buyer goes instead.

### 4. Launch + guardrails

- Grandfathering rule stated before launch. Anti-metrics: conversion rate by tier, expansion revenue, support load per tier.
- Review window: 30 days, one owner, kill/pivot thresholds pre-registered.

## Red Flags

| Thought | Reality |
|---------|---------|
| "Competitor charges X, so we charge X-10%" | Their costs and value aren't yours. Your evidence decides. |
| "Let's add a free tier for growth" | Free is a CAC decision with support costs. Price the support or gate the tier. |
| "More tiers = more choice" | Choice paralyzes. 3 tiers, one obvious. |
| "We'll figure out packaging later" | Packaging IS the product for buyers. Decide now. |

## Checklist

1. **Job per tier** — one sentence each
2. **Value metric** — scales with user success, named explicitly
3. **WTP evidence** — probe type + n + threshold, logged
4. **3-tier structure** — segment, quota, differentiator, price, non-goals
5. **Grandfathering + anti-metrics + 30-day review owner**
