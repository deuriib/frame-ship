# Pi Tool Mapping

How people skills map to Pi native tools.

| People skill need | Pi tool | Notes |
|---|---|---|
| Task tracking (checklists) | `todo` | One todo per checklist item, complete in order |
| Subagent dispatch (parallel interviews, evidence review) | `subagent` via supervisor | Independent talent work only, never the HARD-GATE approval itself |
| Read org docs, briefs, scorecards | `read` | Read-only exploration allowed before approvals |
| Write briefs, scorecards, decision packages | `write` / `edit` | Only after the path's approval gate passes |
| Verify state (headcount, bands, dates) | `bash` | Read-only checks; never send messages via shell |
| Memory of people decisions | `memory_search` | Durable context only, never a substitute for fresh evidence |
