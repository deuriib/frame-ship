## Cuándo usar

- Investigar **keywords** o clasificar **intención transaccional, informacional, inbound**.
- Detectar **canibalización** (dos URLs peleando el mismo intent).
- Mapear qué URL ataca qué búsqueda antes de escribir.

Si ya hay mapa 1 URL = 1 intent, pasa a `contenidos-turbo`.

## Proceso

1. **Extraer intenciones.** Lista las búsquedas reales del nicho con su formato ganador (comparativa, guía, reseña, precio). El formato del top 3 revela el intent mejor que cualquier herramienta.
2. **Clasificar transaccional / informacional / inbound.** Transaccional = quiere comprar (mejor, opiniones, precio). Informacional = quiere aprender (qué es, cómo). Inbound = problema amplio que luego convierte (guías que capturan volumen y derivan a transaccionales).
3. **Mapear 1 URL = 1 intent.** Cada intent una URL. Agrupa variantes de la misma intención en una sola página; separa intenciones distintas aunque compartan palabras.
4. **Marcar canibalizaciones.** Dos URLs existentes mismo intent = flag rojo. Decide cuál gana (más tráfico, más enlaces, mejor conversión) y anota fusión o redirección para `escalar-analitica`.

## Porqué negocio

El intent clasificado decide la monetización: transaccional vende hoy, informacional construye volumen que deriva a venta, inbound captura mercado. Una URL por intent evita que tus propias páginas se roben el ranking y diluyan el CTR.

## Checklist

- [ ] Cada keyword con intent clasificado (T / I / inbound).
- [ ] Mapa 1 URL = 1 intent, sin huérfanos ni duplicados.
- [ ] Canibalizaciones marcadas con URL ganadora propuesta.
- [ ] Prioridad por ROI (transaccionales de alto margen primero).
