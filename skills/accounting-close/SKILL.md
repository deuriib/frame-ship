# Accounting Close — Cierre que Cuadra

**Announce at start:** "Using accounting-close to run the close."

## Procedure

1. **Checklist de cierre.** Ingresos, gastos, bancos, CxC, CxP, inventario, activos fijos, nómina, impuestos. Cada línea: responsable + fecha + evidencia. Asientos manuales solo con soporte + revisión secundaria. Sin evidencia, no cierra.
2. **Conciliaciones.** Banco, CxC, CxP, intercompañías: saldo contable vs externo, diferencia explicada o ajuste registrado. Diferencia sin explicar = cierre bloqueado.
3. **Cortes.** Ingresos y gastos en su periodo (devengo). Lo que cruza el mes se provisiona o se difiere — nunca "lo metemos el próximo mes".
4. **Estados.** Balance (A = P + E, siempre), P&L del periodo + acumulado, flujo de caja. Comparado contra mes anterior con varianzas >10% explicadas.
5. **Bloqueo.** Periodo cerrado en sistema + reporte firmado + archivo de soportes. Reabrir requiere motivo escrito.

## Guardrails

- **Contabilidad:** partida doble, base devengo; checklist de cierre enforced, no opcional.
- **Revenue recognition** per norma — ningún adelanto/diferimiento sin política escrita.
- **FX / intercompañía / transfer pricing** documentado + revisado, nunca "lo cuadramos después".
- **Cierre mes/trimestre/año con sign-off;** cada ajuste con pista (quién/cuándo/por qué/soporte); estados revisados por CFO/controller pre-release.
- **Sin off-books:** nada de cash fuera de libros, pasivos no registrados, o spreadsheets sombra como verdad.

## Rules

1. Ningún asiento sin soporte. Ninguno; manual = soporte + revisión secundaria.
2. Conciliación sin diferencia inexplicada: tolerancia cero o umbral escrito en el brief.
3. Partidas relacionadas declaradas; nada con "parte vinculada" se esconde.
4. Moneda y tipo de cambio del periodo declarados.
5. El cierre tiene fecha límite; el retraso se escala con causa, no con silencio.

## Verification

- [ ] Todas las conciliaciones cuadran o tienen ajuste registrado
- [ ] Balance cuadra; varianzas >10% explicadas
- [ ] Asientos manuales con soporte + revisión secundaria
- [ ] Sign-off registrado; periodo bloqueado + soportes archivados
